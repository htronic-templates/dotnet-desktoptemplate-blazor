# Readme

An example cross platform desktop / web application using PhotinoX / PhotinoX.Blazor

## Application Libs

 * Desktop2.App - This is the main application razor control library  
   All the other projects are Frontends for this one library that contains the application gui

## Frontends

This example is a desktop app with a webview that uses PhotinoX

  * Desktop2.GUI.PhotinoX

These examples use WebAssembly / WebServer

  * Desktop2.GUI.WebWasm
  * Desktop2.GUI.WebServer

This example uses the WebAuto template.
This initially loads a page to preview the page before the web assembly is fully loaded

  * Desktop2.GUI.WebAuto
  * Desktop2.GUI.WebAuto.Client

## Libs

PhotinoX is a frontend that allows desktop apps to be designed using blazor controls

  * https://github.com/ivanvoyager/PhotinoX
  * https://github.com/ivanvoyager/PhotinoX.Blazor

This template uses BlazorBlueprint UI for the components

  * https://blazorblueprintui.com
